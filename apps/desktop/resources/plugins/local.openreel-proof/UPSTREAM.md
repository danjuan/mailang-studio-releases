# Bundled OpenReel Video

The bundled 0.2.14 short-drama build uses the stable
`local.openreel-proof` plugin ID and `editor` view. The source, build inputs,
and contract tests for this resource are maintained in `vendor/openreel`.
The editor and host adapter use draft format 2 with workspace-local media and
revision history.

The original editor and adapter are MIT-licensed. Their initial imported
revisions were OpenReel Video `f818d429d61bd8a6657ae1bd494eda99269649ad`
and PI OpenReel Plugin `1efde897d3fb77f02017c238e025edac27e3fae3`. See
`LICENSE`, `LICENSE-mediabunny`, and the accompanying third-party notices.
